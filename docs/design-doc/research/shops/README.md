## Quick comparison

| | Balatro | The Bazaar |
|---|---|---|
| When you shop | After every Blind beaten (fixed) | One of three encounter choices in an Hour (optional) |
| Stock | 2 random cards + 2 packs + 1 voucher | One themed merchant (tag / size / tier filter) |
| Prices | Set per item and rarity, + edition | 2 × size × 2^tier |
| Reroll | $5, +$1 per reroll, resets each shop | Flat 2/4/6/8 by merchant tier |
| Selling | Half price, any time | Half price (Value), any time; some merchants pay more |
| Upgrading | Vouchers, Planets, Tarots (no merging) | Two same-tier copies merge to next tier |
| Saving money | Interest: $1 per $5, capped | Income stat paid each day |
| Permanent shop changes | Vouchers | Day gating unlocks higher-tier merchants |
