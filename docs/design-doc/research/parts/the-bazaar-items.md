# The Bazaar: All Items

All 636 items on The Bazaar wiki's item database, pulled on 2026-11-03.

Source: https://thebazaar.wiki.gg (Cargo table `items`). The wiki can lag behind live patches, especially for the newest heroes (Stelle, Jules), so treat numbers as a snapshot.

## How items work (summary)

- Each hero has a 10-slot board. Items are **Small** (1 slot), **Medium** (2) or **Large** (3).
- Most items have a **cooldown**; when it fills, the item activates. Combat is fully automatic, so the build is the decision.
- Items start at a **tier** (Bronze → Silver → Gold → Diamond → Legendary) and upgrade by buying/merging copies; values written `a/b/c` scale per tier from the starting tier up.
- **Tags** (types) such as Weapon, Tool, Friend, Aquatic, Tech, Food let other items reference them ("adjacent Weapons", "your Friends").
- Status keywords: Damage, Shield, Heal, Burn, Poison, Regen, Haste, Slow, Freeze, Charge, Crit, Multicast, Ammo, Value/Income.
